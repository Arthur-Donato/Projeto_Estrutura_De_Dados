# Projeto para Estrutura De Dados

Repositório dedicado à implementação de algoritmos clássicos de busca e ordenação na linguagem Java. O objetivo principal desse projeto é consolidar os conhecimentos da disciplina e aplicar na prática esses algoritmos para entender os conceitos de complexidade de tempo e espaço estudados na disciplina de Estrutura de Dados.

## 📋 Algoritmos Implementados
### Algoritmos de Busca (Searching): 
* Busca Linear ( Recursiva e Iterativa);
* Busca Binária ( Recursiva e Iterativa)

### Algoritmos de Ordenação (Sorting): 
* Bubble Sort;
* Selection Sort;
* Insertion Sort;
* Merge Sort;
* Quick Sort;
* Counting Sort;
